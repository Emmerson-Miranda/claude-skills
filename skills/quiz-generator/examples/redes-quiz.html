¿Cuál es la función principal de la capa de transporte en el modelo OSI?

Medium
Modelo OSI · modelo-osi capa-transporte

La capa de transporte (capa 4) gestiona la entrega confiable de extremo a extremo usando protocolos como TCP. El enrutamiento es capa 3, las señales son capa 1, y las sesiones son capa 5.

¿Cuáles de las siguientes características corresponden al protocolo TCP? Selecciona todas las que apliquen.

Hard
TCP/IP · tcp protocolos capa-transporte

TCP es orientado a conexión (handshake de 3 vías), implementa control de flujo con ventana deslizante y usa ACKs para confirmar entrega. UDP (no TCP) ofrece menor latencia y no garantiza orden.

¿Qué protocolo de la capa de aplicación se utiliza para resolver nombres de dominio a direcciones IP?

Easy
Protocolos de Aplicación · dns capa-aplicacion protocolos

DNS (Domain Name System) traduce nombres de dominio legibles (como www.ejemplo.com) a direcciones IP. DHCP asigna IPs dinámicamente, FTP transfiere archivos y SMTP envía correo electrónico.

¿Cuál es la dirección IP de loopback estándar en IPv4?

Easy
Direccionamiento IP · ipv4 direccionamiento loopback

127.0.0.1 es la dirección de loopback estándar en IPv4, usada para que un host se comunique consigo mismo sin pasar por la red física. Las demás son direcciones privadas válidas pero no son loopback.

¿Cuáles de las siguientes son capas del modelo OSI? Selecciona todas las que apliquen.

Medium
Modelo OSI · modelo-osi capas fundamentos

El modelo OSI tiene 7 capas: física, enlace de datos, red, transporte, sesión, presentación y aplicación. La capa de acceso a la red pertenece al modelo TCP/IP, no al OSI. La capa de virtualización no existe en ninguno de los dos modelos.
